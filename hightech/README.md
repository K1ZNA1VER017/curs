# Веб-приложение «Высокие технологии» — биржа заказов и исполнителей

Курсовой проект: динамический сайт компании-франчайзи «1С» с личными кабинетами,
публикацией заказов, откликами фрилансеров и админ-панелью.

**Стек:** HTML5, CSS3, JavaScript, PHP 8, MySQL (MySQL-8.0 в OpenServer 6), phpMyAdmin.
Статичные страницы из исходного макета (заявки, тестовые страницы проектов) переработаны
в полноценное веб-приложение с базой данных.

---

## 1. Возможности системы

### Гость (без регистрации)
* главная страница со статистикой, свежими заказами, категориями и услугами;
* лента заказов с фильтрами (категория, сложность, бюджет, статус, поиск) и сортировкой;
* страница заказа: описание, условия, заказчик, число откликов;
* каталог исполнителей и публичный профиль фрилансера;
* каталог услуг компании и страница услуги;
* форма обратной связи (сообщения сохраняются в БД).

### Заказчик
* регистрация и вход, личный кабинет с редактированием профиля и сменой пароля;
* публикация заказов (категория, бюджет, срок, сложность, требуемые навыки);
* редактирование, отмена, повторное открытие и завершение своих заказов;
* просмотр откликов, **принятие** отклика (исполнитель назначается, заказ → «В работе»)
  или отклонение;
* статистика по своим заказам.

### Фрилансер
* регистрация с профилем: специализация, навыки, ставка, опыт, описание;
* отклик на заказ: предложенная стоимость, срок, сопроводительное письмо;
* защита от повторного отклика на один заказ;
* отзыв своего отклика; список откликов со статусами («Ожидает», «Принят», «Отклонён»);
* публичный профиль с портфелем выполненных заказов.

### Администратор (админ-панель `/admin/`)
* дашборд: счётчики заказов/пользователей/откликов, суммарные бюджеты,
  диаграмма распределения заказов по категориям, последние события;
* **пользователи**: поиск, фильтры по роли и статусу, создание, редактирование,
  блокировка/разблокировка, удаление, смена пароля пользователю;
* **заказы**: поиск и фильтры, быстрая смена статуса, полное редактирование
  (включая заказчика и исполнителя), удаление;
* **отклики**: модерация (принять / отклонить / вернуть в ожидание), удаление;
* **категории**: CRUD-справочник (автоматическая генерация slug, иконки, порядок сортировки);
* **услуги**: CRUD-каталог, скрытие услуги с сайта;
* **сообщения**: обработка обращений из формы обратной связи.

### Реализованная безопасность
* пароли — `password_hash()` / `password_verify()` (bcrypt), без хранения в открытом виде;
* все запросы к БД — только подготовленные выражения PDO (защита от SQL-инъекций);
* вывод данных экранируется функцией `e()` (`htmlspecialchars`, защита от XSS);
* CSRF-токены для всех POST-форм, проверка прав по ролям на каждой странице;
* сессии с регенерацией ID при входе; блокировка доступа заблокированным пользователям.

## 3. Установка в OpenServer 6 (пошагово)

1. **Скопируйте папку `hightech`** в каталог доменов OpenServer:
   `OSPanel\domains\hightech`
   (важно: файлы должны лежать в **корне домена**, тогда все ссылки вида `/orders.php`
   и `/assets/img/...` работают без правок).
2. Запустите OpenServer, включите модули **PHP 8.x** и **MySQL-8.0** (или MariaDB 10.4+).
3. Откройте **phpMyAdmin**: `http://localhost/phpmyadmin` (или через меню OpenServer).
4. **Импорт базы**: вкладка «Импорт» → выберите файл `sql/database.sql` → «Вперёд».
   Скрипт сам создаёт базу `hightech_portal`, все таблицы и демонстрационные данные.
5. Проверьте `config/config.php` — параметры должны соответствовать вашей локальной БД:

   ```php
   return [
       'host'     => 'MySQL-8.0',      // имя модуля БД в OpenServer (или 127.0.0.1)
       'dbname'   => 'hightech_portal',
       'user'     => 'root',
       'password' => '',
       'charset'  => 'utf8mb4',
   ];
   ```

   > Если у вашего root-пользователя установлен пароль — укажите его в поле `password`.
   > Если MySQL работает на стандартном порту и по IP, укажите `'host' => '127.0.0.1'`.

6. Откройте сайт: `http://hightech` (OpenServer сам создаёт домен по имени папки).
7. Войдите под демонстрационной учётной записью и проверьте админ-панель `/admin/`.

### Демонстрационные доступы

| Роль | Логин | Пароль |

| Администратор | `admin@hightech.ru` | `admin123` |

## 4. Схема базы данных (6 таблиц)

| Таблица | Назначение | Ключевые связи |
|---------|-----------|----------------|
| `users` | пользователи: заказчики, фрилансеры, администраторы | 1 → N `orders.customer_id`, 1 → N `responses.freelancer_id` |
| `categories` | категории заказов (1С, интеграции, аналитика…) | 1 → N `orders.category_id`, `services.category_id` |
| `services` | каталог услуг компании | N → 1 `categories` |
| `orders` | заказы заказчиков | N → 1 `users` (заказчик и исполнитель), `categories` |
| `responses` | отклики фрилансеров на заказы | N → 1 `orders`, `users`; уникальный индекс `(order_id, freelancer_id)` |
| `messages` | обращения из формы обратной связи | — |

Каскадные связи: удаление пользователя удаляет его заказы и отклики;
удаление заказа удаляет его отклики; удаление категории оставляет заказы без категории
(`ON DELETE SET NULL`).

## 5. Оформление интерфейса

Вся визуальная тема вынесена в отдельный файл `assets/css/theme.css`, который подключается
последним и переопределяет базовые стили. Это позволяет менять оформление, не затрагивая
исходную вёрстку и логику приложения.

Что в теме:

* дизайн-токены (палитра, тени, радиусы, focus-ring) и современная типографика;
* тёмная «шапка-герой» с янтарным свечением, сеткой и метриками на карточках;
* единый стиль кнопок (pill-форма), карточек, таблиц, значков статусов и форм;
* тёмный подвал со стилизованными ссылками;
* отдельные стили админ-панели (боковое меню, дашборд, панели);
* адаптивность до 390 px, включая выезжающее мобильное меню.

### Если после обновления файлов изменения не видны

Ссылки на `base.css`, `app.css`, `theme.css` и `app.js` подставляются с параметром версии
(функция `asset()` в `includes/functions.php`), поэтому браузер автоматически загружает
свежую версию стилей. Если вы всё же видите старый дизайн:

1. обновите страницу с очисткой кэша — **Ctrl + F5** (Windows) или **Cmd + Shift + R** (macOS);
2. в OpenServer перезапустите модуль PHP (меню «Перезапуск»);
3. убедитесь, что открываете файлы из папки `hightech`, а не старый архив.

### Исправленные ошибки оформления

1. **Кнопки в шапке («Войти», «Регистрация») были растянуты и текст обрезался.**
   Причина: в исходном `base.css` класс `.btn-outline` имел `width: 100%`, а `.btn` —
   `overflow: hidden` с эффектом блика. В теме ширина кнопок ограничена содержимым,
   полноширинными остаются только `.btn-block` и кнопки-действия внутри форм.
2. **Ссылки в подвале были браузерного синего цвета.**
   Причина: в `base.css` для ссылок подвала не были заданы стили. Теперь ссылки
   в подвале (и все текстовые ссылки на сайте) имеют единый янтарный акцент при наведении.
3. **Заголовки-ссылки в карточках заказов и откликов** получили тёмный цвет
   с подсветкой при наведении вместо сплошного акцентного цвета.
4. **Ссылка-логотип** в шапке тоже задана явно — браузерный синий цвет больше не появится
   даже если изображение логотипа не загрузится.
5. **Узкие экраны (320–420 px)**: добавлен компактный режим шапки (уменьшены отступы,
   логотип и кнопки) — кнопки «Войти» и «Регистрация» полностью помещаются на экране
   без обрезки и горизонтальной прокрутки. Проверено на ширинах 320, 360, 390, 420, 768,
   1024 и 1440 px.

## 6. Частые вопросы при защите/проверке

* **«Ошибка подключения к базе данных»** — не импортирован `sql/database.sql`
  или неверные параметры в `config/config.php`.
* **Краказябры вместо русского текста** — при импорте убедитесь, что выбрана кодировка
  `utf8mb4` (в дампе уже указано `SET NAMES utf8mb4`).
* **Ссылки ведут на несуществующие страницы** — проект должен быть размещён в корне домена,
  а не во вложенной папке.
* **Как проверить разграничение прав** — войдите заказчиком (заказ можно создать,
  но нельзя откликнуться), затем фрилансером (можно откликаться, но нельзя создавать заказы),
  затем администратором (доступны все разделы админ-панели).
* **Скриншот `config.php` из задания** соответствует реальному файлу проекта
  `config/config.php` (те же ключи `host`, `dbname`, `user`, `password`, `charset`).

## 7. Если после замены файлов ничего не изменилось

Типичные причины — по убыванию вероятности:

### 1. В папке домена остались файлы прошлой версии

Откройте папку домена (`OSPanel\domains\<ваш-домен>`) и удалите из неё всё, что относится
к старому статическому сайту:

```
index.html            ← главный виновник: сервер может открывать именно его
projects.html         services.html         contacts.html
project-*.html        service-*.html        prpject-template.html
styles.css            img/ (папка со старыми картинками)
```

Нужны только файлы нового проекта: `index.php`, `admin/`, `assets/`, `config/`, `includes/`,
`sql/`, `check.php`, `README.md` и остальные `.php`-файлы из архива.

### 2. Архив распаковался во вложенную папку

Если после распаковки получилась структура `domains/hightech/hightech/…`, приложение
не заработает: ссылки вида `/assets/css/theme.css` ведут в корень домена.
Поднимите файлы на один уровень вверх или используйте архив **`hightech-domain.zip`** —
в нём файлы лежат в корне архива, и он распаковывается прямо в папку домена без лишних уровней.

Правильная структура папки домена:

```
domains/hightech/
├── index.php
├── admin/
├── assets/
├── config/
├── includes/
├── sql/
└── ...остальные .php файлы
```

### 3. Кэш браузера

Обновите страницу с очисткой кэша: **Ctrl + F5** (Windows) или **Cmd + Shift + R** (macOS).
В новой сборке ссылки на CSS и JS подставляются с версией файла (функция `asset()`),
поэтому после этой правки стили обновляются автоматически.

### 4. Как убедиться, что открывается новая версия

* Прокрутите сайт вниз: **в подвале должна быть строка
  «сборка 11.10.2026 · тема v2 (современный дизайн)»**. Если её нет — открыты старые файлы.
* Откройте страницу **`http://<ваш-домен>/check.php`** — самодиагностика проверит PHP,
  расширения, файлы, остатки старых страниц, подключение к БД и таблицы, а найденные
  проблемы отметит красным с подсказкой. Для работы сайта этот файл не нужен,
  после проверки его можно удалить.

### 5. OpenServer

* перезапустите OpenServer (меню «Перезапуск»);
* убедитесь, что для домена выбран **PHP 8.x** (OpenServer → «Модули» → PHP 8.x);
* проверьте, что модуль **MySQL-8.0** запущен и база `hightech_portal` импортирована.
