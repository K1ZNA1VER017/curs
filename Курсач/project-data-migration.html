Миграция данных между системами

180 000 руб. Срок: 18 дней

Описание проекта

Перенос данных из старой системы учета (самописное решение на FoxPro) в новую конфигурацию 1С:Управление торговлей 11.4. Проект включает анализ данных, разработку инструментов миграции и тестирование результатов.

Заказчик - оптовая компания, работающая на рынке 15 лет. Накоплен значительный объем исторических данных, которые необходимо сохранить для отчетности и анализа.

Основная задача: Обеспечить бесперебойный переход на новую систему с сохранением всей критически важной информации.

Объем миграции

  • Справочники:
    • Контрагенты (5,000+ записей)
    • Номенклатура (25,000+ позиций)
    • Склады и подразделения (15+)
    • Сотрудники (80+ человек)
  • Остатки:
    • Товарные остатки на дату перехода
    • Денежные средства
    • Взаиморасчеты с контрагентами
  • Исторические данные:
    • Документы продаж за 3 года (150,000+ документов)
    • Документы закупок за 3 года (80,000+ документов)
    • Движения денежных средств

Технические аспекты

Источник данных: FoxPro 9.0, DBF файлы

Целевая система: 1С:Управление торговлей 11.4.12.125

Платформа 1С: 8.3.18

Подход к миграции: Разработка специализированных обработок выгрузки/загрузки

Формат обмена: XML через веб-сервисы или прямые вызовы API 1С

Валидация: Многоуровневая проверка целостности данных

Требования к исполнителю

Обязательные требования:

  • Опыт миграции данных в 1С не менее 3 лет
  • Знание FoxPro и формата DBF файлов
  • Опыт работы с 1С:Управление торговлей 11
  • Умение разрабатывать сложные обработки миграции
  • Понимание принципов трансформации данных
  • Опыт работы с XML и веб-сервисами в 1С

Желательные навыки:

  • Опыт миграции из FoxPro в 1С
  • Знание SQL для анализа исходных данных
  • Опыт работы с большими объемами данных
  • Знание методов оптимизации процессов миграции

План проекта

  • Фаза 1: Анализ (3 дня) - Изучение структуры исходных данных и mapping с целевой системой
  • Фаза 2: Разработка (7 дней) - Создание инструментов миграции и тестовых сценариев
  • Фаза 3: Тестирование (5 дней) - Пробная миграция, выявление и исправление проблем
  • Фаза 4: Продуктивная миграция (2 дня) - Финальный перенос данных
  • Фаза 5: Сопровождение (1 день) - Поддержка в первые дни работы

Критерии качества

  • Полнота миграции - не менее 99.5% данных
  • Точность преобразования - соответствие бизнес-логике
  • Производительность - миграция должна уложиться в отведенное время
  • Документирование - полное описание процесса и mapping
  • Поддержка - возможность повторного запуска при необходимости
