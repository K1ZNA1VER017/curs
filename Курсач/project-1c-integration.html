Интеграция 1С с веб-магазином

150 000 руб. Срок: 14 дней

Описание проекта

Требуется интеграция конфигурации 1С:Розница с существующим интернет-магазином на WordPress. Проект включает настройку двустороннего обмена данными между системами.

Клиент - розничная сеть с 5 филиалами, которая расширяет свой бизнес в онлайн-пространство. Необходимо обеспечить синхронизацию данных в реальном времени для эффективного управления запасами и заказами.

Цель проекта: Создать единое информационное пространство для офлайн и онлайн продаж, исключить двойной ввод данных и снизить количество ошибок при учете.

Задачи проекта

  • Настройка обмена товарами и категориями из 1С в WordPress
  • Синхронизация цен и остатков товаров в реальном времени
  • Автоматическая выгрузка заказов из WordPress в 1С
  • Интеграция системы скидок и акционных предложений
  • Настройка обмена статусами заказов
  • Создание механизма обработки ошибок при обмене
  • Разработка административного интерфейса для управления обменом
  • Создание подробной документации по работе интеграции
  • Обучение персонала работе с системой

Требования к исполнителю

Обязательные требования:

  • Опыт работы с 1С не менее 3 лет
  • Глубокое знание механизмов обмена данными в 1С
  • Опыт интеграции 1С с веб-системами
  • Знание REST API и веб-сервисов
  • Опыт работы с WordPress и WooCommerce
  • Понимание принципов работы интернет-магазинов

Желательные навыки:

  • Опыт работы с XML/JSON
  • Знание PHP для доработки WordPress
  • Опыт работы с базами данных MySQL
  • Знание JavaScript для фронтенд-доработок

Технические требования

1С: 1С:Розница 2.3, платформа 8.3.18

WordPress: Версия 6.0+, WooCommerce 7.0+

Обмен: REST API, JSON формат

Частота обмена: Реальное время для заказов, ежечасно для товаров

Безопасность: HTTPS, аутентификация по токену

Логирование: Подробное логирование всех операций обмена

Критерии успеха

  • Синхронизация данных происходит без ошибок в 99% случаев
  • Время отклика системы не превышает 2 секунд
  • Система корректно обрабатывает одновременные запросы
  • Обеспечена отказоустойчивость при сбоях связи
  • Персонал обучен и может самостоятельно работать с системой
