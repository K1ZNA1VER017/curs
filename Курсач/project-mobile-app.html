Разработка мобильного приложения для учета

300 000 руб. Срок: 30 дней

Описание проекта

Создание кроссплатформенного мобильного приложения для удаленного ввода данных в систему 1С через REST API. Приложение должно работать на iOS и Android.

Цель проекта - предоставить сотрудникам компании возможность вводить данные о продажах и остатках товаров непосредственно с мобильных устройств во время выездных мероприятий, инвентаризаций и торговых визитов.

Особенности проекта: Приложение должно работать в офлайн-режиме с последующей синхронизацией данных при появлении интернет-соединения.

Задачи проекта

  • Разработка кроссплатформенного мобильного приложения на React Native
  • Интеграция с REST API системы 1С:Предприятие 8
  • Реализация офлайн-работы с локальной базой данных
  • Создание интерфейса для ввода данных о продажах и возвратах
  • Разработка модуля инвентаризации товаров со сканированием штрих-кодов
  • Реализация системы авторизации и разграничения прав доступа
  • Настройка push-уведомлений о новых заданиях и статусах
  • Создание административной панели для управления мобильными пользователями
  • Тестирование на различных устройствах и iOS/Android версиях

Требования к исполнителю

Обязательные требования:

  • Опыт разработки на React Native не менее 2 лет
  • Знание REST API и работы с бэкенд-системами
  • Опыт интеграции мобильных приложений с 1С или другими ERP-системами
  • Понимание принципов офлайн-работы приложений и синхронизации данных
  • Опыт публикации приложений в AppStore и Google Play

Желательные навыки:

  • Опыт работы с базами данных SQLite
  • Знание TypeScript
  • Опыт работы с системами сканирования штрих-кодов
  • Знание принципов Material Design и Human Interface Guidelines

Функциональные требования

Основные модули:

  • Авторизация по логину/паролю
  • Рабочий стол с текущими заданиями
  • Модуль ввода продаж с выбором товаров
  • Модуль инвентаризации со сканированием штрих-кодов
  • Просмотр остатков товаров
  • История операций
  • Настройки приложения

Технические требования:

  • Поддержка iOS 12+ и Android 8+
  • Работа в портретном и альбомном режиме
  • Поддержка темной и светлой темы
  • Локализация на русский язык

Критерии приемки

  • Приложение стабильно работает на 10+ тестовых устройствах
  • Офлайн-режим корректно сохраняет данные и синхронизирует при подключении
  • Время отклика интерфейса не превышает 100 мс
  • Приложение проходит модерацию в AppStore и Google Play
  • Предоставлена полная документация и исходный код
