Оптимизация базы данных 1С

120 000 руб. Срок: 10 дней

Описание проекта

Комплексная оптимизация производительности базы данных 1С:ERP для крупного производственного предприятия. Система работает медленно, особенно при формировании отчетов и проведении документов.

Текущая база данных имеет размер около 150 ГБ, количество пользователей - 80+. Наблюдаются проблемы с блокировками и длительным временем отклика в пиковые часы нагрузки.

Цель проекта: Увеличить производительность системы на 50% и снизить время отклика в 2 раза.

Задачи проекта

  • Анализ текущей производительности и выявление узких мест
  • Оптимизация структуры базы данных и индексов
  • Настройка параметров СУБД для оптимальной работы с 1С
  • Реорганизация таблиц и перестроение индексов
  • Создание плана обслуживания базы данных
  • Оптимизация самых медленных запросов
  • Настройка мониторинга производительности
  • Создание рекомендаций по дальнейшему поддержанию производительности
  • Тестирование производительности после оптимизации

Техническая среда

СУБД: Microsoft SQL Server 2019

1С: 1С:ERP Управление предприятием 2.4

Платформа 1С: 8.3.18

Размер БД: ~150 ГБ

Пользователи: 80+ одновременных подключений

Сервер: Windows Server 2019, 32 ГБ RAM, SSD диски

Требования к исполнителю

Обязательные требования:

  • Опыт оптимизации баз данных 1С не менее 3 лет
  • Глубокое знание Microsoft SQL Server
  • Опыт работы с большими базами данных (100+ ГБ)
  • Знание архитектуры 1С:Предприятие и принципов работы с СУБД
  • Умение анализировать планы выполнения запросов
  • Опыт настройки индексов и статистики

Желательные навыки:

  • Сертификация Microsoft по SQL Server
  • Опыт работы с 1С:ERP
  • Знание PowerShell для автоматизации задач
  • Опыт настройки Always On Availability Groups

Метрики успеха

  • Время открытия основных форм сокращено на 50%
  • Время проведения документов не превышает 5 секунд
  • Время формирования отчетов сокращено на 60%
  • Устранены блокировки в пиковые часы работы
  • Создана система мониторинга производительности
  • Предоставлен детальный отчет о проделанной работе
