Разработка дашборда аналитики

200 000 руб. Срок: 21 день

Описание проекта

Создание интерактивного дашборда для визуализации ключевых бизнес-показателей на основе данных из 1С и внешних источников. Проект включает разработку ETL процессов и создание пользовательского интерфейса.

Заказчик - торговая компания с сетью из 15 магазинов. Необходимо предоставить руководству инструмент для мониторинга эффективности бизнеса в реальном времени.

Основная цель: Создание единой точки доступа к ключевым метрикам бизнеса с возможностью детализации и анализа трендов.

Функциональные требования

  • Продажи: Динамика продаж, выполнение плана, анализ по товарным категориям
  • Финансы: Выручка, прибыль, рентабельность, дебиторская задолженность
  • Запасы: Оборачиваемость товаров, уровень запасов, анализ неликвидов
  • Магазины: Сравнительная эффективность по точкам продаж
  • Клиенты: Анализ клиентской базы, повторные покупки, средний чек
  • Персонал: Эффективность продавцов, выполнение KPI
  • Интерактивность: Фильтры по периодам, магазинам, товарным группам
  • Оповещения: Автоматические уведомления при отклонениях показателей

Техническая архитектура

Источники данных:

  • 1С:Управление торговлей 11.4
  • Excel файлы с планами продаж
  • Веб-сервис для данных о макроэкономических показателях

ETL процесс: Ежедневное обновление данных в ночное время

Хранилище данных: SQL Server Analysis Services (SSAS)

Визуализация: Power BI с веб-публикацией

Доступ: Веб-браузер, мобильное приложение Power BI

Требования к исполнителю

Обязательные требования:

  • Опыт разработки дашбордов в Power BI не менее 2 лет
  • Знание DAX и M Language
  • Опыт интеграции Power BI с 1С через OData или другие протоколы
  • Понимание принципов построения хранилищ данных
  • Опыт работы с SQL Server и SSAS
  • Знание основ бизнес-аналитики и KPI торговых компаний

Желательные навыки:

  • Опыт работы с 1С:Управление торговлей
  • Знание Python для ETL процессов
  • Опыт настройки row-level security в Power BI
  • Сертификация Microsoft по Power BI

Этапы проекта

  • Проектирование структуры данных и метрик (3 дня)
  • Настройка ETL процессов и хранилища данных (5 дней)
  • Разработка прототипа дашборда (4 дня)
  • Согласование и доработка визуализации (3 дня)
  • Настройка безопасности и публикация (2 дня)
  • Обучение пользователей и передача документации (4 дня)
